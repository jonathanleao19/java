# ☕ Java | Generation Brasil

Repositório dedicado aos exercícios e atividades desenvolvidos durante minha formação no **Bootcamp Java Full Stack da Generation Brasil**.

O objetivo deste repositório é registrar minha evolução nos fundamentos da linguagem Java, desde lógica de programação até conceitos essenciais para o desenvolvimento orientado a objetos.

## 📚 Conteúdos praticados

- Lógica de programação
- Variáveis e operadores
- Estruturas condicionais
- Estruturas de repetição
- Arrays
- Métodos
- Programação Orientada a Objetos (POO)
- Collections
- Exercícios práticos
- Atividades avaliativas

## 🛠️ Tecnologias

- Java
- Eclipse / Spring Tool Suite
- Git
- GitHub

## 🎯 Objetivo

Consolidar os fundamentos de Java por meio da prática e construir uma base sólida para o desenvolvimento de aplicações back-end com Java e Spring.
