# 🎮 Gamer Zone API

API REST desenvolvida em **Java com Spring Boot** para gerenciamento de jogos e categorias.

Projeto desenvolvido durante minha formação em Java Full Stack, com foco na construção de uma API REST, persistência de dados, relacionamentos entre entidades, validações e operações CRUD.

---

## 🚀 Tecnologias

- ☕ Java 17
- 🌱 Spring Boot
- 🗄️ Spring Data JPA
- 🔗 Hibernate
- 🛢️ MySQL
- ✅ Jakarta Validation
- 🧪 Insomnia
- 📦 Maven
- 🔀 Git e GitHub

---

## 📌 Sobre o projeto

O **Gamer Zone** é uma API para gerenciamento de jogos e suas respectivas categorias.

A aplicação permite realizar operações de cadastro, consulta, atualização e exclusão de categorias e jogos.
